# Applications

The [Applications](/apps) page shows every service that is registered with the application server: the program, the instance name, how long it has been up, its memory and the host it runs on. Open a card for the instance's own page.

## Application server

An application server instance has two tabs.

**Logs** shows the entries the services have sent. Narrow them by application, by date and by a text filter; the refresh button reloads, and the view buttons choose and save which columns are shown and how they are sorted.

**Log Settings** lists the log levels the instance is running with, by tag. A change is pushed to the running service straight away and applies until the service restarts.

## Gateways and OPC servers

A gateway or OPC server card opens that instance's page, described under [Gateways](/help/gateways).
