Jde OPC Gateway, version **{{version}}**.

The site, its libraries and the C++ services are built and released together under one version number.

## Components

| component | what it is |
|---|---|
| Web site | this Angular application |
| Jde.AppServer | application server: sign-in, access database, log collection |
| Jde.OpcGateway | OPC UA client gateway |
| Jde.OpcServer | OPC UA server |
| Jde.Opc.Hub | the application server and gateway in one process |
